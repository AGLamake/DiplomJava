# Информационная система охранного агентства (Java, JSF)

Веб-приложение на Jakarta Faces 4.0 (Mojarra) + PrimeFaces + PostgreSQL, работает в Apache Tomcat 10.1.
Это перенос дипломного WinForms-приложения: мониторинг охраны автомобилей и недвижимости, вызов ГБР и МЧС,
справочники и разграничение прав по ролям.

## Требования

- JDK 21
- Maven 3.9+
- PostgreSQL 14+ (проверялось на 16)
- Tomcat 10.1 — только для развёртывания на своём сервере; `mvn cargo:run` скачивает его сам

## Подготовка базы данных

```powershell
chcp 65001                                              # чтобы сообщения psql читались в консоли
psql -U postgres -c "CREATE DATABASE security"
psql -U postgres -d security -1 -f sql/01_schema.sql    # сначала схема
psql -U postgres -d security -1 -f sql/02_seed.sql      # потом демонстрационные данные (по желанию)
```

Ошибка `отношение "clients" не существует` означает, что `02_seed.sql` запущен до `01_schema.sql`.
Нечитаемые сообщения psql (`Р?РЁР?Р'Р?Р?`) — признак того, что консоль не переключена на UTF-8 (`chcp 65001`);
на данные в базе это не влияет.

Для автотестов нужна отдельная база `security_test`. Тесты сами пересоздают в ней схему,
настройки лежат в `src/test/resources/db-test.properties`:

```powershell
psql -U postgres -c "CREATE DATABASE security_test"
```

## Настройки подключения

Скопируйте `src/main/resources/db.properties.example` в `src/main/resources/db.properties`
и укажите пароль — этот файл попадёт в war. Внешний файл имеет приоритет: его путь задаётся системным
свойством JVM `security.db` (для `mvn cargo:run` по умолчанию — `db.properties` в этой папке,
другой файл: `-Dsecurity.db=путь`).

Время прибытия ГБР и МЧС (в секундах) задаётся в `src/main/resources/app.properties`.

## Запуск

```powershell
mvn test                    # автотесты (нужен запущенный PostgreSQL)
mvn package cargo:run       # сборка и запуск в Tomcat: http://localhost:8080/security-agency/
mvn -DskipTests package     # только сборка target\security-agency.war
```

Другой порт: `mvn cargo:run -Dhttp.port=8081`. Для своего Tomcat 10.1 скопируйте
`target\security-agency.war` в его папку `webapps`.

## Первый вход

Первый зарегистрированный пользователь становится **администратором**. Остальные регистрируются
как операторы, и войти они смогут только после того, как администратор включит учётную запись
в разделе «Пользователи». Там же администратор назначает роль.

## Роли

| Раздел | Админ. | Менеджер | Инженер | Оператор | Сотрудник ГБР |
|---|---|---|---|---|---|
| Автомобиль / Недвижимость (мониторинг) | ✎ | — | — | ✎ | — |
| Тревоги и выезды | ✎ | 👁 | — | ✎ | 👁 |
| Клиенты, объекты, автомобили | ✎ | ✎ | 👁 | 👁 | — |
| Договоры | ✎ | ✎ | — | 👁 | — |
| ГБР | ✎ | 👁 | — | 👁 | 👁 |
| Оборудование | ✎ | 👁 | ✎ | 👁 | — |
| Заявки на монтаж | ✎ | ✎ | ✎ | — | — |
| Мои выезды | — | — | — | — | ✎ |
| Пользователи | ✎ | — | — | — | — |
| Журнал действий | 👁 | — | — | — | — |

✎ — просмотр и изменение, 👁 — только просмотр. Роль «Клиент» в приложение не входит.
Страница раздела без права просмотра отвечает «403 Доступ запрещён».

## Структура

```
sql/                        схема и демо-данные
tools/make_scheme_images.py вырезает схемы машины/квартиры из скриншотов диплома
src/main/java/ru/vlsu/security/
  config/      подключение к БД, настройки
  security/    роли, матрица прав, хэширование паролей (PBKDF2)
  model/       записи (record) и статусы
  dao/         доступ к таблицам через JDBC
  service/     вход/регистрация, тревоги, выезды ГБР, журнал действий
  monitoring/  логика датчиков и таймеров ГБР/МЧС (без UI и БД)
  web/         JSF-бины: сессия, фильтр доступа, общая таблица/форма, разделы, мониторинг
src/main/webapp/
  *.xhtml      страницы разделов, вход, ошибка
  WEB-INF/     шаблоны (layout, table), включаемые фрагменты, web.xml, beans.xml, faces-config.xml
  resources/   CSS, JS, картинки схем
```
